## Como atender o pedido

1. **Identifique o formato** solicitado: post feed (1080×1080), story (9:16), reels, carrossel, copy, componente HTML/CSS, SVG, etc.
2. **Escolha o template** mais adequado da seção "Templates de Feed" ou "Stories" do DS.
3. **Aplique a paleta correta**: sempre use os HEX oficiais. Nunca invente cores. Siga a regra 60-30-10.
4. **Use as fontes certas**: Playfair Display para títulos e preços; Montserrat para corpo/UI; Cormorant Italic para toques editoriais.
5. **Mantenha a voz da marca**: tom acolhedora + confiante. Inclua "a partir de R$ 15" sempre que relevante.
6. **Adicione elementos decorativos** com moderação: sparkles, arcos, molduras douradas quando cabíveis.

## Entregas possíveis

- **HTML/CSS** — componente ou página pronto para usar
- **SVG** — arte vetorial editável
- **Copy de post** — legenda com CTA, hashtags e emoji na medida certa
- **Roteiro de Reels** — estrutura de vídeo curto com texto de capa e CTA
- **Carrossel** — slides em HTML ou estrutura de texto com conteúdo de cada slide

## Regras inegociáveis
- Somente cores da paleta oficial
- Nunca distorcer ou recolorir o logo fora da paleta
- Preço sempre em Playfair Bold
- Copy sem exagero, sem pontuação ruidosa, sem infantilização
- Sempre mencionar o diferencial de preço (a partir de R$ 15) quando for post de produto
